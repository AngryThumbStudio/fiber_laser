# Mechanical Files

3D models, jigs, and supporting hardware used with the fiber laser workflows in this repository. Most coin-related tools are parametric so they can be resized before printing.

## Coin Workholding & Finishing

* [**coin-edge-jig**](./coin-edge-jig/README.md) — Parametric two-part magnetic jig for rotary edge engraving on coin blanks.
* [**bradan-lane-coin-polishing-tool**](./bradan-lane-coin-polishing-tool/README.md) — Parametric holder/shroud for coin buffing and polishing. Design by [bradanlane](https://gitlab.com/bradanlane/fiber_laser_coins) (MIT License); OpenSCAD and Fusion 360 sources included here.

## Focus Calibration

These files support the [Ramp Card Focus Calibration Procedure](../ramp_card_method.md):

* [**fatlab-designs-focus-tools**](./fatlab-designs-focus-tools/) — Ramp card SVG and stand STLs from Fatlab Designs (attribution in the ramp card guide).
* [**ramp-card-jig**](./ramp-card-jig/) — Bed-mountable ramp card jig (`ramp_card_jig.zip`).
